## Overview

This repository documents my hands-on development of Linux administration skills as part of the Charlie Whiskey Security Labs environment.

The goal is to build practical familiarity with Linux systems while developing skills that support security engineering, SIEM engineering, and modern infrastructure environments.

Rather than serving solely as a command reference, this repository will evolve to include practical administration exercises, troubleshooting scenarios, and hands-on labs as my Linux experience grows.

## Objectives

- Develop confidence working from the Linux command line
- Understand Linux filesystem structure and navigation
- Manage files, users, groups, and permissions
- Work with processes, services, packages, and system logs
- Develop Linux networking and troubleshooting skills
- Build familiarity with Linux-based security and infrastructure tooling
- Establish a foundation for Docker and Kubernetes environments
